# Reference claims ledger: what the three videos report

Every substantive claim in the three reference documentaries (codes RZ, SM, AG: see `transcript-analysis.md`), with the
timestamp and the exact caption text that supports it. This is the worked example of how YouTube documentaries enter a Jad
Tak research ledger: **as secondary sources, kept, cited and checked, never discarded for being YouTube and never promoted
to fact by repetition.**

It also serves the Neem Karoli Baba project directly. The `Jad Tak` column links the claim to the facts table in
`channels/jadtak/videos/neem-karoli-baba-hanuman-ansh/neem-karoli-baba-hanuman-ansh-research.md` (F1 to F28) where one
exists.

**Status words** (defined in `templates/research-ledger.md`): `established`, `reported`, `account`, `video-reported`,
`conflicting`, `dramatized`, `unsupported`. Auto captions (SM, AG) garble some words; where a caption is plainly a
mishearing, the note says so, and the excerpt is kept as captioned.

**How to narrate each status** (summary): `video-reported` and `account` stories are told in full, with one natural
attribution at the start ("भक्त यह कहानी आज भी सुनाते हैं"); `conflicting` uses the corroborated version or a rounded one;
`dramatized` material gives the event only, never the film's invented dialogue or names; `unsupported` is not used.
